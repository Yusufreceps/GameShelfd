# GameShelfd

Bu proje BLM2537 Ağ Tabanlı Programlama dersi için geliştirmiş oldupğum bir projedir. 

# Kullanılan Teknolojiler
* HTML5 (Semantik etiketler kullanılmıştır).
* CSS3 (Flexbox ve Grid ile sayfa düzeni sağlanmıştır. Mobile uyumludur).
* JavaScript (DOM manipulasyonu, form doğrulaması ve localStorage veri yönetimi kullanılmıştır).

## Nasıl açılır ve çalıştırılır?
Proje herhangi bir harici sunucu veya veritabanı kurulumu gerektirmez. Veriler `localStorage` belleğinde saklanır. Projeyi bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyebilirsiniz:
1. Bu depoyu bilgisayarınıza indirin.
2. İndirdiğiniz proje klasörünü **Visual Code Studio (VS Code)** editörü ile açın.
3. VS Code içerisine **Live Server** eklentisinin kurulu olduğundan emin olun (soldaki eklentiler bölümünde **Live Server** adı ile aratıp kurabilirsiniz).
4. Klasör içerisindeki `index.html` dosyasına sağ tıklayp **Open with Live Server** seçeneğine tıklayın.
5. Proje varsayılan tarayıcınızda açılacaktır.
